# 岸词 · 设计约定

原生 macOS 菜单栏应用，AppKit 管理窗口与浮动层，SwiftUI 管理内容。

- 信息层次：当前播放器 → 歌曲与进度 → 当前歌词 → 来源与可恢复的错误。
- 侧栏：正在播放、歌词来源、显示与外观、隐私与诊断。
- 系统字体与 SF Symbols；不加载远程字体、图标或图片。
- 设置页遵循系统明暗模式。播放卡片使用墨色底、浅薄荷强调色、白色正文。
- 原生按钮、选择框、开关与文件选择器；所有图标按钮具备辅助功能标签。
- 只在当前行变化时滚动歌词；尊重系统减少动态效果设置。
- 未找到歌词时展示明确原因与添加目录、手动选文件的恢复入口。
- 播放器读取与歌词文件来源严格区分；目录不是播放器支持范围。
- 底部歌词条点击穿透，鼠标靠近时隐藏；不遮挡日常点击。
- 不虚构纯文本歌词的播放时间；没有时间轴时明确标注。

UI/UX Pro Max 检索结果作为对比度、交互反馈与空状态的参考；实现使用原生桌面规范，不引入网页页面结构。
